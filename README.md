# 타바코테라피 (TabacoTherapy)

금연을 돕는 정적 웹페이지입니다. `index.html` 파일 하나로 동작해요.

- 금연 시간, 안 피운 개비 수, 아낀 돈 실시간 카운터
- 화면 위에 항상 떠 있는 "내가 끊는 이유"
- "지금 담배가 당겨요" — 3분 호흡 타이머
- "나 의지가 약해진다…" — 지금까지 해낸 것과 상황별 대처법
- 계속 피우면 생기는 일 (연초 / 궐련형 / 액상형)
- 절약 통장: 아낀 돈, 1주·1달·1년 예상, 목표 달성일, 이 돈이면 살 수 있는 것
- 사이버 담배: 젤로맥스 · 네스티 일회용 30000 · 릴 하이브리드 · 연초, 액상 맛 13가지, 랜덤 켁켁

기록은 브라우저(localStorage)에만 저장됩니다.

도움이 필요하면: 금연상담전화 1544-9030 (무료), 보건소 금연클리닉
